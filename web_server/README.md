# alu-system_engineering-devops
Web server project: contains scripts to configure and manage an Ubuntu web server.
- web_server/0-transfer_file: transfers a file to a server using scp- web_server/1-install_nginx_web_server: installs nginx and serves Holberton School on port 80
- web_server/2-setup_a_domain_name: my domain name
- web_server/3-redirection: adds a 301 redirect on /redirect_me
- web_server/4-not_found_page_404: adds a custom 404 page with Ceci n'est pas une page
- web_server/5-design_a_beautiful_404_page.html: my creative 404 page
