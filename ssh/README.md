# SSH Project
This project teaches how to connect to a remote server using SSH and an RSA key pair.

- 0-use_a_private_key: it connects to my server with my private key
- 1-create_ssh_key_pair: this creates a 4096-bit RSA key pair
- 2-ssh_config: this is my SSH client configuration
- 100-puppet_ssh_config.pp: this Puppet script sets up my SSH client config
